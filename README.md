# WayVR Website

[wayvr.org](https://wayvr.org)

## Development

Run locally with Hugo extended (SCSS support):

```sh
hugo server -D
```

Build for production:

```sh
hugo
```

The site uses the [hugo-book](https://github.com/alex-shpak/hugo-book) theme as a git submodule.
Initialize submodules after cloning:

```sh
git submodule update --init --recursive
```
